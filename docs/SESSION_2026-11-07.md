## Fixed tonight (each one is a release)

1. **0.4.2.26** the puppet was drawn 90, then 180 degrees off: the drawn component must be aligned with its actor; the
   hero mesh's own `-90` was a red herring. `pose_yaw.txt` allows dialling in.
2. **0.4.2.27** a seated NPC hopped every few seconds: the mirror replayed its clip from frame 0; it now continues.
3. **0.4.2.28** a seated NPC's arm gesture broke off and looped: the mirror's own animation blueprint adds a second clip
   of the same family; same-family clips are now left alone.
4. **0.4.2.29/30** NPC mirrors stood sideways: the mesh offset has to travel as a **relative** angle
   (`actor 8, mesh world -82, mesh relative -90` on the host), not as a world yaw and not as zero.
5. **0.4.2.31** a released NPC could not walk: `release()` restored possession, collision and animation but not the
   movement component's tick, which the mirror path switches off.
6. **0.4.2.32** the two PCs ran different cores (host `coopdll_109`, packages `coopdll_106`), which made the game
   report *"this save was made with a different modlist"*; one core now ships for both.

Also: `diag_link.ps1` (the guest serves its logs, the host reads them) started by the launcher, and the firewall script
now opens UDP 40001-40002 and TCP 40003-40004.

## How to start a session tomorrow

1. Host first: the shortcut with `role = auto`; the guest after, with `role = guest` in `settings.ini`.
2. Both must run the same package version (0.4.2.32 at the time of writing) - otherwise the game warns about the mod
   list and the modules can disagree about the protocol.
3. If something looks wrong: `.\tools\diag_link.ps1 fetch -Peer <guest>` and read both logs from one place.
