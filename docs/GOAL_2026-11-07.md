## 14 — автоматические проверки

* `tools\check_online.ps1` — одна команда: инварианты + аудит загрузок + рост лога (VERDICT green);
* `tools\cooptest.ps1` — 16/16 зелёные; починены: сравнение версий модулей по содержимому, роль гостя по заголовку
  окна, `missing` как «не растёт», срезы лога по времени, гигиена лога на обеих копиях; новые сценарии `reconnect`,
  `reload_busy`, `pickup_both`, `trade_buyout`;
* `tools\deploy.ps1` — сверяет **содержимое** выкаченных модулей, а не устаревший отпечаток;
* `tools\blackbox.ps1` — читает установленный лог, берёт базу исключений, считает их инкрементально, пишет память
  каждой копии и умеет смотреть вторую копию через мост (`-Peer`); на паре обязателен `-NoProbe`;
* `tools\session_report.ps1` — сводная страница по длинной сессии: сливает **все** файлы истории рекордера (перезапуск
  рекордера — норма, и брать только свежий файл значит терять историю), тянет гостя через мост;
* **сборка стала воспроизводимой**: в `native\build_module.bat` добавлен `/Brepro`. До этого две сборки одного и того
  же исходника отличались PE-меткой времени, и «модули совпадают по содержимому» нельзя было проверить между машинами.
  Проверено: две сборки подряд дают один хеш, а пересборка развёрнутого `npc` побайтово совпала с установленным файлом;
* `docs\RUNBOOK.md` — как всё это запускать самому.
