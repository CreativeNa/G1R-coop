# Прозрачность сборки (как проверить, что в архиве)

Мы не просим верить на слово: исходники открыты, сборка детерминированная, хеши публикуются.
Любой может собрать те же файлы сам и сравнить SHA-256.

## 1. Что где лежит

| Что | Файл в репозитории |
|---|---|
| загрузчик (23 строки, `OpenProcess` → `VirtualAllocEx` → `WriteProcessMemory` → `CreateRemoteThread(LoadLibraryA)`) | `native/inject.c` |
| ресурс версии загрузчика | `native/inject.rc` |
| манифест `asInvoker` | `native/inject.manifest` |
| ядро мода | `native/coopdll.c` |
| семь модулей | `native/*_module.c` |
| сборка ядра и загрузчика | `native/build.bat` |
| сборка модулей | `native/build_module.bat` |
| упаковка установщика | `tools/make_installer_package.ps1` |

Лицензия — MIT (`LICENSE`): читать, собирать и распространять можно свободно.

## 2. Детерминированность

Сборка идёт MSVC с флагом **`/Brepro`** (убирает метки времени и пути из PE), поэтому у всех, кто собирает
тот же коммит с той же версией Visual Studio Build Tools, получаются **побайтово те же файлы**.

Требования к окружению: Visual Studio 2022 Build Tools, MSVC x64 (`vcvars64.bat`), как в `native/build.bat`.

## 3. Как собрать и сравнить

```powershell
# из корня репозитория, на нужном теге/коммите
cd native
.\build.bat          # coopdll.dll + inject.exe
.\build_module.bat   # modules\*.dll
cd ..
.\tools\make_installer_package.ps1 -Version 0.5.3 -CoreDll coopdll_111.dll
.\tools\verify_hashes.ps1 -Package dist\Gothic1Coop-Setup-0.5.3
```

`verify_hashes.ps1` печатает SHA-256 каждого файла из `payload` и сверяет его с `payload\manifest.json`
(этот же манифест проверяет установщик перед распаковкой). Если хоть один файл не совпал — скрипт вернёт
код 1 и строку `MISMATCH`.

## 4. Что сравнивать в скачанном архиве

1. Сначала убедитесь, что SHA-256 самого zip совпадает с тем, что указан рядом с релизом.
2. Распакуйте, запустите `tools\verify_hashes.ps1 -Package <распакованная папка>`.
3. Дополнительно: `payload\manifest.json` содержит размер и SHA-256 каждого файла — установщик их проверяет.

## 5. Проверено на этой сборке

Пакет `0.5.3` собран **из того же коммита, что помечен тегом** `v0.5.3`. Все восемь файлов
(`inject.exe`, `coopdll_111.dll`, семь модулей) собраны из исходников этого коммита.

Воспроизводимость проверена двойной сборкой подряд: `inject.exe`, ядро и все модули дали **те же SHA-256**.
`__DATE__`/`__TIME__` из ядра убраны — именно они раньше делали каждый билд уникальным.
## 6. Чего в бинарниках нет

- сетевого кода в загрузчике;
- чтения паролей, браузера, буфера обмена;
- работы с файлами игры;
- обхода антивируса, упаковщиков, обфускации, шифрования кода.

Загрузчик умеет только одно: загрузить указанную DLL в указанный процесс и напечатать адрес загрузки.
