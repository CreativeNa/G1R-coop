# Чек-лист парной сессии (2 ПК)

Короткий план: что подготовить, что нажимать, что проверить и что прислать.
Подробнее — `TWO_PC_TEST.md`, `HOW_TO_PLAY.md`.

## 0. До запуска (на обоих ПК)

- [ ] Игра **одной сборки**: build 1.2 или новее (обновления Steam на время теста лучше приостановить).
- [ ] Один и тот же архив мода: `Gothic1Coop-Setup-0.5.3.zip` (SHA-256 `ABEFCADA…` — сверить).
- [ ] Мод установлен, на рабочем столе ярлык **«Gothic 1 Remake Co-op»**.
- [ ] Radmin VPN: оба в одной сети, видите адреса друг друга `26.x.x.x`.
- [ ] Брандмауэр: игра разрешена в **частных** сетях (UDP 40001, 40002; TCP 40003, 40004).
- [ ] Игра закрыта, лишние окна закрыты (для чистоты логов).
- [ ] **Сделайте копию своих сохранений** — на всякий случай.

## 1. Хост

1. [ ] Ярлык «Gothic 1 Remake Co-op» — **первым**.
2. [ ] Дождаться игры, загрузить сохранение.
3. [ ] **F5** — сохраниться (обязательно: гость грузит именно последнее сохранение хоста).
4. [ ] Записать время (ЧЧ:ММ) — дальше по нему искать в логах.
5. [ ] Проверить в `%LOCALAPPDATA%\G1RCoop\logs\launcher.log`: `role: host`.

## 2. Гость (после того, как хост в игре)

1. [ ] Ярлык «Gothic 1 Remake Co-op».
2. [ ] Лаунчер должен сам найти хоста и забрать его сохранения.
3. [ ] Если не подключился — в главном меню **«Присоединиться»** один раз.
4. [ ] Загрузить **сохранение хоста** (не своё).
5. [ ] Проверить в своём `launcher.log`: `role: guest` и адрес хоста.

## 3. Что проверять в игре (по порядку, с временем)

| # | Проверка | Ожидание | Время |
|---|---|---|---|
| 1 | Виден персонаж друга | двигается, без прыжков | |
| 2 | Предметы: выбросить стопку, друг подбирает | количество совпадает | |
| 3 | Сундук: один открывает, второй видит крышку | второй не открывает | |
| 4 | Диалог с NPC на хосте | гость видит реакцию мира | |
| 5 | Смерть одного | умирает/возрождается у обоих согласованно | |
| 6 | **F9 один раз** | одна загрузка у обоих, меню работает | |
| 7 | Время суток | расходится не больше пары минут | |
| 8 | Задание/журнал | запись появляется у обоих | |
| 9 | Торговля | кошелёк и запас видны; деньги у каждого свои | |
| 10 | Сон | экран темнеет у обоих, просыпаются в одно время | |
| 11 | Убитый NPC | лежит, а не стоит | |
| 12 | 30–60 минут обычной игры | без крашей и рассинхрона | |

## 4. Если что-то не так — сразу записать

- время (ЧЧ:ММ) и что делали;
- кто видел проблему: хост или гость;
- текст ошибки/окна, если было;
- скриншот.

## 5. Отчёты (на обоих ПК, после сессии)

```powershell
powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\G1RCoop\tools\collect_logs.ps1" -Note "что случилось и во сколько"
```

или двойной клик по **«Собрать отчёт.bat»** в папке мода.

- [ ] Архив `report_<host|guest>_<время>.zip` появился в `%LOCALAPPDATA%\G1RCoop\beta_reports`
- [ ] Приложен заполненный `docs/BETA_REPORT_TEMPLATE.md`
- [ ] Скриншоты (если проблема визуальная)

## 6. Красные флаги (останавливаемся и разбираемся)

- Двое хостов: оба в логе `role: host` → перезапуск, хост первым.
- Гость не забрал сохранения: в его логе `savesync fetch returned …` → миры будут разные.
- `LoadLibrary returned 0x0` в логе → мод не внедрился, присылать отчёт сразу.
- Игра падает при подключении → отчёт с обоих ПК, ничего не перезапускать до сбора.

## 7. Что делать с результатом

- [ ] Если всё прошло — сообщить «сессия чистая», можно выпускать `0.5.3`.
- [ ] Если были проблемы — прислать оба архива и заполненный шаблон.
