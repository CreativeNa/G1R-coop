# Security / Безопасность

## English

Versions up to and including 0.5.4.5 have a security issue. **Please update to the latest release** (Releases page). Host and guest must run
the same version.

Play only in a private VPN room (for example Radmin VPN with a password) with people you know.

**Reporting a vulnerability:** use **Security → Report a vulnerability** in this repository (private report). Please do not publish details
in a public issue.

## Русский

В версиях до 0.5.4.5 включительно есть проблема безопасности. **Обновитесь до последнего релиза** (страница Releases). У хоста и гостя
должна быть одна и та же версия.

Играйте только в закрытой VPN-комнате (например, Radmin VPN с паролем) с людьми, которых знаете.

**Сообщить об уязвимости:** кнопка **Security → Report a vulnerability** в этом репозитории (закрытое сообщение). Не публикуйте подробности
в открытых issue.
